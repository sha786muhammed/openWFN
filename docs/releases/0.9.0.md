# openWFN 0.9.0 — unreleased

The source package targets 0.9.0. No release date or PyPI publication is claimed
here. The last published release documented by this preparation is 0.8.2.

## Install the source checkout

```bash
python -m pip install -e ".[interop,outputs,mcp]"
openwfn --version
```

The optional extras are separate. The base installation does not require
IOData, cclib, or the MCP SDK. Package-index installation of 0.9.0 should only
be documented as available after the release has been published and checked.

## Support boundaries

| Workflow | Status and required data |
| --- | --- |
| Native FCHK CLI/API analysis | Existing interfaces retained; each analysis requires the corresponding source records. Numerical validation remains fixture-scoped. |
| Additional format ingestion | Stable fixture contract for the pinned 25-format inventory, using IOData 1.0.1 where required. Not a guarantee for every file variant. |
| Structure-only inputs | Partial summaries and supported structural operations; no invented orbitals, populations, or density. |
| Mixed-format batches | Capability-aware results and explicit unsupported/failed inputs. Format hints/maps may be needed for ambiguous files. |
| QC output `properties` / `read_output()` | Experimental source-reported extraction through cclib 1.8.1; missing properties remain null or empty. Not a full wavefunction or registered batch analysis. |
| Local MCP | Experimental stdio adapter using SDK 2.2.0. Inspection, registry analyses, and output properties only. Binary `.chk` inputs are rejected. |
| Periodic and integral-only inputs | Preserve supported components; general molecular electronic analyses are not promised for these inputs. |
| REST or remote MCP service | Not provided. No public upload or authentication service is included. |

See [the format matrix](../reference/formats-and-exports.md),
[output properties](../output-properties.md), and [MCP](../mcp.md).

## Python migration

`load(path).data` is now an `OpenWFNData` container. Scripts that accessed
low-level calculation fields directly should use `.data.calculation` and check
that it is not `None`. Prefer the high-level methods and file-specific
capability inspection for automation. Result schema 1.0 remains in use.

The new `properties` command reads QC logs independently of `load()`. A log may
report frontier energies or atomic charges without containing the coefficients,
basis, and density matrices needed to recompute those quantities.

## Verification

The preparation recorded 570 passing local tests and two skips. CI on the
merged source passed Python 3.10–3.13 tests, macOS/Windows smoke checks,
interoperability contracts, scientific validation, optional-interface tests,
and wheel installation. Release metadata changes must be checked again before
publication; this evidence describes the preceding merged implementation.

Five water representations come from one originating calculation and test
conversion consistency. Selected real ORCA, Q-Chem, and Gaussian outputs were
compared with source values. Neither establishes universal molecule, method,
or file-version coverage. Quantitative density work still requires grid
convergence and inspection of conservation diagnostics.
