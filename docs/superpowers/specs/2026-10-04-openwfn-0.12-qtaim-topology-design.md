# openWFN 0.12 QTAIM Topology Design

## Purpose

PR #54 adds a conservative first-party QTAIM topology engine on top of the analytic density-gradient/Hessian field engine introduced in PR #52. The implementation must be useful for routine isolated-molecule analysis while making numerical limits and incompleteness explicit.

This PR does **not** claim exhaustive topology reconstruction and does not promote QTAIM to Stable/Validated. The method remains **Experimental** until independent molecular reference comparisons and broader convergence evidence are committed.

## Scientific scope

The engine may identify nondegenerate electron-density critical points with the standard rank/signature labels:

- `(3,-3)` nuclear attractor critical point (NCP): three negative Hessian eigenvalues;
- `(3,-1)` bond critical point (BCP): two negative and one positive Hessian eigenvalue;
- `(3,+1)` ring critical point (RCP): one negative and two positive Hessian eigenvalues;
- `(3,+3)` cage critical point (CCP): three positive Hessian eigenvalues.

Classification is based on the eigenvalues of the symmetric density Hessian at a converged stationary point. Degenerate/near-zero curvature must be reported as unclassified rather than forced into a QTAIM label.

## Search contract

Critical-point search is deterministic, finite, and bounded.

- Inputs are either explicit seed points in bohr or deterministic molecular seeds generated from nuclear positions, atom-pair midpoints, and the molecular centroid.
- Search uses Newton steps from the analytic density gradient/Hessian, with a finite trust radius and bounded iteration count.
- Steps outside a padded molecular bounding box are rejected.
- Ill-conditioned or singular Hessians use an explicit pseudoinverse threshold; failure to reduce the gradient residual terminates that seed without fabricating convergence.
- A point is converged only if `||grad rho||` is below the configured residual tolerance and its density/Hessian are finite.
- Duplicate converged points are merged only within a documented spatial tolerance and only when classifications are compatible.
- Seed count and stored critical-point count are capped.

Default bounded search is **not exhaustive**. The result must therefore carry a completeness warning even when the Poincare-Hopf relation is satisfied. Explicit user seed sets are also not treated as proof of completeness.

## Topology diagnostics

For every critical point report:

- Cartesian position in bohr;
- density, gradient residual norm, Laplacian;
- Hessian eigenvalues in ascending order;
- Hessian rank and signature;
- standard QTAIM label when nondegenerate;
- iteration count and converged status;
- nearest atom index/distance when applicable.

For the total converged CP set report counts by type and the finite-system topology relation

`N_NCP - N_BCP + N_RCP - N_CCP = 1`.

Failure of this relation is a strong incompleteness diagnostic, not an exception. Satisfying it is necessary but not sufficient evidence of completeness.

## Bond paths

For each converged `(3,-1)` BCP, attempt two density-gradient ascent traces from small displacements along `+/-` the Hessian eigenvector associated with the positive eigenvalue.

- Integrate the normalized density gradient with bounded step size and maximum path length/step count.
- Terminate a branch when it enters the nuclear capture radius of an atom, when the gradient is nonfinite/too small away from a capture region, when it leaves the allowed molecular box, or when the step limit is reached.
- A resolved bond path requires the two branches to terminate at two distinct atoms.
- Store path points in bohr, endpoint atom indices, total path length, and a resolved flag.
- Unresolved paths remain in the result with an explicit reason; they are never silently discarded.

Bond paths in this PR are topology diagnostics only. Basin surfaces, atomic charges, delocalization indices, and atomic energies are outside scope.

## Resource and API rules

- Reuse `evaluate_density_fields`; do not duplicate AO derivative code.
- Runtime work remains chunked/bounded and must not allocate an unbounded molecular grid.
- Defaults must cap seeds, Newton iterations, path steps, and stored path points.
- Public Python output is a renderer-independent `ResultRecord` with explicit units, conventions, warnings, and Experimental validation status.
- Register the analysis as `qtaim` in the shared analysis registry using isolated-molecule, basis, and total-density capability requirements.
- CLI/report/Workbench visualization and cross-interface presentation are deferred to PR #57; this PR may expose QTAIM through the generic registry/public Python surface only.

## Validation requirements for PR #54

Unit tests must cover:

1. exact Hessian-signature classification including degenerate rejection;
2. bounded Newton convergence on analytic synthetic stationary fields independent of the AO evaluator;
3. duplicate merging and resource caps;
4. topology-relation diagnostics;
5. bond-path tracing on a synthetic two-attractor density field;
6. registry payload shape, units, Experimental status, warnings, and capability gating;
7. a real wavefunction smoke test showing finite QTAIM output without claiming external agreement.

Independent agreement against PySCF-derived density fields and/or an established QTAIM implementation is required before status promotion, but broader validation evidence is intentionally deferred to the later validation gate.

## Explicitly deferred

- exhaustive adaptive global CP discovery;
- zero-flux basin construction and basin integration (PR #56);
- QTAIM atomic charges and atomic energies;
- delocalization/localization indices;
- source-program-specific QTAIM import/reconciliation;
- CLI tables, HTML report panels, Workbench rendering, REST/MCP presentation polish (PR #57);
- Stable/Validated status.
