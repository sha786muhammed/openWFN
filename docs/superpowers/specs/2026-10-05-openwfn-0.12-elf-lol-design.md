# openWFN 0.12 ELF/LOL Design

## Purpose

Add scientifically conservative Electron Localization Function (ELF) and Localized Orbital Locator (LOL) analyses on top of the shared analytic real-space density and positive-definite kinetic-energy-density engine introduced in PR #52.

This PR is the scientific core only. CLI tables, report/workbench rendering, surface controls, and generalized volumetric presentation remain a later presentation PR. NCI and basin integration remain separate scientific gates.

## Scientific definitions

openWFN already defines the positive-definite kinetic-energy density as

`tau = (1/2) sum_i n_i |grad psi_i|^2`.

All formulas below are written for that convention. No alternate kinetic-energy-density convention may be silently substituted.

### ELF

For one spin channel `sigma`:

- `D_sigma = tau_sigma - |grad rho_sigma|^2 / (8 rho_sigma)`
- `D0_sigma = (3/10) (6 pi^2)^(2/3) rho_sigma^(5/3)`
- `ELF_sigma = 1 / (1 + (D_sigma / D0_sigma)^2)`

For a restricted closed-shell total density, the equivalent spin-neutral form is:

- `D = tau - |grad rho|^2 / (8 rho)`
- `D0 = (3/10) (3 pi^2)^(2/3) rho^(5/3)`
- `ELF = 1 / (1 + (D / D0)^2)`

Implementation should use the algebraically stable form `D0^2 / (D0^2 + D^2)` after validity checks.

A value of 0.5 is the homogeneous-electron-gas reference. The exact single-orbital limit has `D = 0` and ELF = 1 away from density-zero tails.

### LOL

Using the same positive-definite KED convention and homogeneous-electron-gas reference:

- `t = tau_HEG / tau`
- `LOL = t / (1 + t)`

Use the stable equivalent `LOL = tau_HEG / (tau_HEG + tau)` after validity checks.

For a restricted closed-shell total density:

- `tau_HEG = (3/10) (3 pi^2)^(2/3) rho^(5/3)`.

For an explicit alpha or beta spin channel:

- `tau_HEG_sigma = (3/10) (6 pi^2)^(2/3) rho_sigma^(5/3)`.

LOL = 0.5 for the homogeneous-electron-gas reference.

## Spin policy

- `channel="total"` is supported only when the calculation is demonstrably restricted closed-shell.
- `channel="alpha"` and `channel="beta"` are supported whenever those density channels can be derived by the existing density-channel rules.
- For restricted closed-shell data, alpha and beta ELF/LOL must numerically equal the total ELF/LOL.
- For open-shell data, a total ELF/LOL must be rejected rather than inventing a spin-averaging convention. The user must request alpha or beta.
- A signed spin-difference ELF/LOL is undefined and is not offered.

## Numerical validity and tails

### Density floor

The default density floor is `1.0e-12 electron/bohr^3`. Points at or below the floor are outside the quantitative domain of the localization descriptor and must be marked invalid rather than assigned an arbitrary localization value.

### Pauli excess

For ELF, exact single-determinant theory gives `D >= 0`. Floating-point noise can make `D` slightly negative. openWFN may clamp only a small negative value satisfying

`D >= -max(1.0e-12, 1.0e-10 * max(tau, D0, 1.0))`.

A more negative value is a diagnostic failure for that point. It must be marked invalid and counted; squaring a materially negative `D` is prohibited because it would hide the failure.

### KED validity

LOL requires nonnegative positive-definite KED. Tiny negative values within the same absolute/relative tolerance may be clamped to zero; materially negative values are invalid and counted.

### Nonfinite values

Any nonfinite rho, gradient, tau, reference value, or final descriptor marks that point invalid.

## Result contract

Add registered analyses:

- `elf` -> result kind `electron_localization_function`
- `lol` -> result kind `localized_orbital_locator`

Both accept explicit `points_bohr`, `channel`, optional `chunk_size`, and optional `density_floor`.

Results include:

- points in Cartesian bohr
- requested channel
- descriptor values with invalid entries serialized as `null`
- `valid_mask`
- source `rho`, `tau`, and homogeneous-electron-gas reference values for reproducibility
- ELF also reports von Weizsaecker/Pauli-excess diagnostics
- exact formula/convention labels
- thresholds used
- invalid-point counts and warnings
- units for every dimensional diagnostic
- validation status `Experimental`

## Resource policy

ELF/LOL must reuse the existing bounded real-space point/chunk machinery. No unbounded mesh or cube allocation is introduced in this PR. Explicit points are subject to the same point ceiling as density derivatives and KED.

## Validation gate

Required tests:

1. homogeneous-electron-gas invariant: ELF = LOL = 0.5;
2. single-orbital ELF limit = 1;
3. restricted closed-shell total/alpha/beta equivalence;
4. open-shell total-channel rejection and alpha/beta support;
5. density-tail invalidation;
6. materially negative Pauli excess/KED invalidation without hiding the sign;
7. tiny floating-point negatives are bounded/clamped only within the documented tolerance;
8. chunked and unchunked equality;
9. registry/result metadata and units;
10. resource-ceiling rejection before AO evaluation;
11. real-wavefunction component comparison against an independent evaluator where available.

Independent external-program ELF/LOL agreement is not yet a release gate. Until such evidence is committed with program/version, input hashes, grids/points, conventions, and tolerances, ELF and LOL remain `Experimental`.
