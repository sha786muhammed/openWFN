# openWFN 0.12 QTAIM Topology Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded, conservative QTAIM critical-point search, classification, topology diagnostics, and bond-path tracing using the analytic real-space density field engine.

**Architecture:** Add one focused `qtaim.py` analysis module that consumes `evaluate_density_fields` and separates stationary-point numerics from molecular seed generation and result serialization. Keep the method renderer-independent and Experimental; register it through the shared analysis registry while deferring dedicated CLI/report/Workbench presentation to PR #57.

**Tech Stack:** Python 3.10-3.13, NumPy, existing openWFN `CalculationData`, analytic real-space evaluator, result registry, pytest/GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-04-openwfn-0.12-qtaim-topology-design.md`

## Global Constraints

- Reuse `evaluate_density_fields`; do not duplicate AO derivative code.
- Standard CP labels are `(3,-3)`, `(3,-1)`, `(3,+1)`, `(3,+3)` only for nondegenerate rank-3 Hessians.
- Degenerate/near-zero curvature is unclassified, never coerced.
- Search is deterministic and bounded by finite seed, iteration, trust-radius, bounding-box, and stored-result limits.
- The default search is not exhaustive and must report incompleteness warnings.
- `N_NCP - N_BCP + N_RCP - N_CCP = 1` is a diagnostic only; satisfying it never upgrades completeness.
- Bond paths are bounded gradient-ascent traces from BCPs and unresolved paths remain explicit.
- Basin integration, QTAIM charges/energies, CLI/report/Workbench presentation, and Stable/Validated promotion are out of scope.
- Existing tests and scientific validation must remain green.

## Review Focus

1. **Near-degenerate Hessians:** eigenvalues at or below curvature tolerance must remain unclassified rather than flip labels numerically. Covered in Task 1.
2. **Runaway Newton seeds:** singular curvature, non-improving steps, or leaving the molecular box must terminate deterministically within limits. Covered in Task 2.
3. **False completeness:** topology relation equality must not suppress the explicit bounded-search incompleteness warning. Covered in Tasks 3 and 5.
4. **BCP path ambiguity:** both trace branches ending at the same atom or failing capture must return unresolved paths with reasons. Covered in Task 4.
5. **Resource growth:** user-provided/generated seeds and stored path points must be capped before large allocations or unbounded loops. Covered in Tasks 2-4.
