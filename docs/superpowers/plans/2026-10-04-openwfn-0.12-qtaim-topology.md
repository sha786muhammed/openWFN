# openWFN 0.12 QTAIM Topology Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded QTAIM critical-point discovery, Hessian classification, and bond-path tracing using the shared analytic density field engine.

**Architecture:** Keep search/refinement, classification, and trajectory integration in separate focused modules. All field values come from the core real-space engine; topology code owns deterministic seed generation, safeguarded refinement, deduplication, completeness diagnostics, and bond-path integration.

**Tech Stack:** Python 3.10-3.13, NumPy linear algebra, existing `ResultRecord`, resource budget, registry, report/Workbench stack.

**Spec:** `docs/superpowers/specs/2026-10-04-openwfn-0.12-real-space-nto-qtaim-design.md`

## Global Constraints

- Solve `grad rho = 0` using analytic gradients/Hessians.
- Classify only non-degenerate rank-3 critical points as `(3,-3)`, `(3,-1)`, `(3,+1)`, `(3,+3)`.
- Near-degenerate Hessians remain ambiguous/unclassified.
- Bounded deterministic seeds: nuclei, internuclear candidates, coarse/adaptive region sampling.
- Refinement and trajectories obey central resource ceilings.
- A bond path succeeds only when both branches terminate at recognized attractors.
- Never claim topology completeness solely because attempted seeds converged.
- Scientific status begins Experimental.

## Review Focus

- Singular/ill-conditioned Hessians must trigger safeguarded fallback or explicit failure, not explosive Newton steps.
- Duplicate critical points from different seeds must merge deterministically without merging physically distinct nearby points.
- Non-nuclear attractors must be representable and not forcibly mapped to nuclei.
- Bond-path cycling/domain-exit/step-exhaustion must be reported as partial failures.
- Search-region boundaries and unresolved seeds must be visible in completeness diagnostics.
