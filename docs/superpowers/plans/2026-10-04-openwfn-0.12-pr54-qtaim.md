**Goal:** Add bounded QTAIM density-topology analysis using PR52 analytic density gradient/Hessian fields, with explicit critical-point residuals, Hessian classification, bond-path termination, and completeness diagnostics.

## Core settings/results

Use immutable explicit settings, e.g.:

```python
@dataclass(frozen=True, slots=True)
class QTAIMSearchSettings:
    gradient_tolerance: float
    position_tolerance_bohr: float
    eigenvalue_tolerance: float
    max_iterations: int
    max_step_bohr: float
    max_seeds: int
    search_padding_bohr: float
    coarse_spacing_bohr: float

@dataclass(frozen=True, slots=True)
class CriticalPoint:
    index: int
    coordinates_bohr: tuple[float, float, float]
    rho: float
    gradient_norm: float
    laplacian: float
    hessian_eigenvalues: tuple[float, float, float]
    hessian_eigenvectors: ...
    rank: int | None
    signature: int | None
    kind: str
    converged: bool

```

Keep numerical arrays internal where convenient, but public results must be serializable and deterministic.

## Task 1 — Generic stationary-point refinement kernel (TDD)

- [ ] Write RED tests using analytic scalar model fields independent of molecular AO code: isotropic maximum, saddle with `(3,-1)`, `(3,+1)`, minimum `(3,+3)`, and a near-degenerate Hessian.
- [ ] Define an internal field callback protocol returning rho/gradient/Hessian at points. This lets analytic model tests exercise the search algorithm without pretending those models are electron densities.
- [ ] Implement safeguarded Newton/trust-region refinement: solve Hessian step when conditioned, clip to `max_step_bohr`, reject/regularize nonfinite or ill-conditioned steps explicitly.
- [ ] Terminate only when gradient residual and displacement/position criteria pass.
- [ ] Bound iterations and domain before/through refinement; return explicit failure reason rather than last iterate as success.

## Task 2 — Hessian classification

- [ ] RED tests for sorted eigenvalues and exact signature definitions:
  - `(3,-3)` attractor
  - `(3,-1)` bond CP
  - `(3,+1)` ring CP
  - `(3,+3)` cage CP
- [ ] Treat `abs(lambda) <= eigenvalue_tolerance` as degenerate/ambiguous; do not force a signature.
- [ ] Return eigenvectors with deterministic sign convention where they are later used for bond-path seeding.
- [ ] Validate Hessian symmetry before diagonalization; symmetrize only within documented numerical tolerance and record residual if useful.

## Task 3 — Deterministic molecular seed generation

- [ ] Seed nuclei exactly (then offset/refine safely to handle nuclear cusp behavior in Gaussian-basis density).
- [ ] Seed internuclear midpoints/line candidates for atom pairs inside a bounded distance policy.
- [ ] Seed a coarse molecule-bounded grid/adaptive candidate set based on low gradient norm and local density/topology indicators.
- [ ] Enforce `max_seeds` before refinement and record counts by seed source.
- [ ] Do not use chemical bonds from `analysis/topology.py` as proof that a QTAIM bond CP exists; graph bonds may only be optional seed hints if clearly labeled.

## Task 4 — Deduplication and completeness diagnostics

- [ ] RED tests with multiple seeds converging to the same analytic CP.
- [ ] Deduplicate only when position and density agree within explicit tolerances; retain source-seed count/labels in diagnostics.
- [ ] Report attempted/converged/failed/deduplicated seed counts, domain exits, ill-conditioned Hessians and unresolved candidates.
- [ ] Compare found attractors to nuclear centers and report missing/unmatched attractors; non-nuclear attractors remain possible and must not be discarded merely because they lack a nucleus.
- [ ] `complete=True` only when the configured bounded search passes its documented completeness checks; otherwise use partial/unknown wording.

## Task 5 — Bond-path integrator

For each converged `(3,-1)` BCP:

- [ ] Select the Hessian eigenvector belonging to its single positive eigenvalue.
- [ ] RED test both `+epsilon` and `-epsilon` starts on analytic model fields whose ascent endpoints are known.
- [ ] Integrate normalized ascent `dr/ds = grad(rho)/|grad(rho)|` with adaptive bounded steps.
- [ ] A path succeeds only when each side reaches a recognized attractor according to the same attractor convergence policy.
- [ ] Detect and report: domain exit, max steps, nonfinite field, gradient collapse away from attractor, cycles/revisits, and ambiguous endpoint.
- [ ] Store sampled path points under a maximum-point ceiling, path length, endpoints, termination reasons and optional density profile.
- [ ] Failed/one-sided trajectories remain partial; never label them a successful bond path.
