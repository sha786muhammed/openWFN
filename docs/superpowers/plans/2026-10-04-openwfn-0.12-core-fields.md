# openWFN 0.12 Core Fields Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the shared analytic AO/density derivative and kinetic-energy-density engine that every 0.12 real-space analysis reuses.

**Architecture:** Extend `src/openwfn/analysis/basis.py` with analytic AO first/second derivatives using the same normalization and pure/cartesian transforms as AO values, then add a focused `real_space.py` layer that contracts AO value/gradient/Hessian arrays with density/orbital data. Register bounded point analyses through the existing analysis registry and central resource budget.

**Tech Stack:** Python 3.10-3.13, NumPy, existing openWFN Gaussian basis engine, `ResultRecord`, current registry/API/CLI/MCP architecture.

**Spec:** `docs/superpowers/specs/2026-10-04-openwfn-0.12-real-space-nto-qtaim-design.md`

## Global Constraints

- Production derivatives are analytic; finite differences are validation only.
- Internally use atomic units; public outputs state units.
- Preserve current contracted normalization and pure/cartesian AO transforms through the supported angular momentum range.
- Use `tau_PD = 1/2 sum_i n_i |grad psi_i|^2`; any Becke-style factor-of-two is explicit at the consumer.
- Bound point batches and AO derivative temporaries before allocation via `src/openwfn/resource_budget.py`.
- All new analyses begin Experimental.
- Front ends consume registry results; they do not recompute science.

## Review Focus

- Pure-shell derivative transforms must match the current AO ordering and normalization, tested against finite differences for pure d/f and the highest supported angular momentum.
- Near-nuclear points must remain finite where the Gaussian basis permits it, with no `nan` from polynomial derivative branches.
- Restricted and unrestricted kinetic-energy density must follow the same occupation/spin convention as the parsed orbital model.
- Oversized point batches must fail before allocating derivative tensors.
- Hessians must be symmetric within tolerance and the returned Laplacian must equal their trace.
