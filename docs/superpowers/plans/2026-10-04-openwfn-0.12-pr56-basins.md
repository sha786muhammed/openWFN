# PR56 Plan — QTAIM Basin Assignment and Integration

**Goal:** Add bounded, convergence-controlled QTAIM basin assignment and integration using PR52 analytic density gradients, PR54 attractors, and the existing deterministic atom-centered quadrature.

**Depends on:** latest green `main` after PR52 and PR54. PR55/PR53 are independent.

**Scientific status:** Experimental.

## Result/settings model

Use explicit settings such as:

```python
@dataclass(frozen=True, slots=True)
class BasinIntegrationLevel:
    radial_points: int
    theta_points: int
    phi_points: int
    radial_extent_bohr: float

@dataclass(frozen=True, slots=True)
class BasinSettings:
    levels: tuple[BasinIntegrationLevel, ...]
    trajectory_max_steps: int
    initial_step_bohr: float
    min_step_bohr: float
    max_step_bohr: float
    attractor_position_tolerance_bohr: float
    gradient_tolerance: float
    population_tolerance_e: float
    charge_tolerance_e: float
    max_unresolved_electrons: float
```

Per-basin records contain attractor identity/location, nuclear association when present, population, charge when nuclear, first moment/dipole, per-level convergence, unresolved contribution and diagnostics.

## Task 1 — Gradient-trajectory basin assignment kernel (TDD)

A point belongs to a basin only if bounded steepest ascent reaches a known PR54 attractor.

- [ ] Build analytic model-field tests with two known attractors and a separatrix; points on either side must terminate at the correct attractor.
- [ ] Add exact-attractor/near-attractor termination tests.
- [ ] Integrate normalized ascent with adaptive step control; do not make trajectory speed depend on raw gradient magnitude.
- [ ] Detect domain exit, max steps, nonfinite gradient, gradient collapse away from an attractor, cycles/revisits, ambiguous proximity to multiple attractors.
- [ ] Return a typed assignment outcome with attractor index or `None`, status and termination reason.
- [ ] Never select “nearest atom” as fallback.

## Task 2 — Safe trajectory caching

- [ ] Add RED tests proving naïve nearest-neighbor caching could cross an analytic basin boundary; this must not be accepted.
- [ ] If caching is implemented, accept a cached basin only when a documented local geometric/gradient-direction consistency test passes and the cached point is within a strict radius.
- [ ] Cache is an optimization only; disabling it must preserve assignments and integrated values within tolerance.
- [ ] Bound cache size and memory.

## Task 3 — Reuse atom-centered molecular quadrature

- [ ] Reuse `iter_atom_centered_chunks()` because its owner-partition weights form a deterministic molecular integration partition; basin identity is determined by gradient trajectory, not by quadrature owner atom.
- [ ] Do not change existing Hirshfeld quadrature defaults. Add settings/refinement plumbing only if required.
- [ ] For each quadrature point evaluate rho once, assign basin, then accumulate `rho * integration_weight` into that basin.
- [ ] Track unresolved quadrature weight and unresolved electron contribution separately.
- [ ] Confirm total resolved+unresolved density integral matches the same whole-molecule quadrature integral.

## Task 4 — Basin populations, charges and first moments

- [ ] Electron population: integrate rho over points assigned to each attractor basin.
- [ ] Nuclear basin charge: `Z_A - N_A` only when a basin attractor is associated unambiguously with a physical nucleus; non-nuclear attractors do not receive a fabricated nuclear charge.
- [ ] First moment/dipole: integrate `(r-r_attractor) rho(r)` with explicit sign/unit convention and report only when converged.
- [ ] Global closure: sum basin populations + unresolved electron contribution versus whole molecular quadrature integral and expected electron count when available.
- [ ] Do not renormalize basin populations/charges to force closure.
- [ ] Do not implement atomic energies in 0.12.

## Task 5 — Multi-level convergence

- [ ] Run deterministic increasing quadrature levels; do not accept a single grid merely because total charge closure looks good.
- [ ] Per basin track population/charge changes from previous level.
- [ ] Global criteria include unresolved electron contribution, unresolved quadrature weight, total electron closure and all requested basin properties.
- [ ] Converged only when final consecutive levels meet documented tolerances; otherwise return partial result with values plus explicit nonconvergence warning.
- [ ] Reject level sequences that are not strictly increasing in meaningful resolution or that exceed point/resource ceilings before starting.
- [ ] Record total trajectories, cached assignments, full integrations, failures by reason, points per level and runtime diagnostics.

## Task 6 — Finite-domain basin volume and zero-flux diagnostics

- [ ] Do not expose an unqualified `volume` field.
- [ ] If requested, implement `volume_at_density_cutoff`: integrate geometric quadrature weight for assigned points satisfying explicit `rho >= cutoff`; store cutoff/radial extent/domain.
- [ ] For optional zero-flux diagnostics, detect neighboring sampled points assigned to different basins, estimate a local boundary normal from assignment/grid geometry, and report sampled `grad rho . n` residual distribution.
- [ ] Label zero-flux sampling as diagnostic evidence, not proof replacing population convergence.

## Task 7 — Registered `qtaim-basins` analysis

- [ ] `qtaim_basins(data, *, topology_settings=..., basin_settings=..., include_first_moments=True, volume_density_cutoff=None)` uses PR54 topology result/engine and PR52 field engine.
- [ ] It may compute topology internally using identical registered defaults if no precomputed topology object is supplied; front ends must not independently perform topology.
- [ ] Register `qtaim-basins` with isolated molecule + basis + total density requirements.
- [ ] Read-only MCP uses conservative bounded defaults and returns basin tables/diagnostics; no cube/files.
- [ ] Serialization must not include millions of trajectory points; detailed failed-point diagnostics are summarized/count-bounded.

## Task 8 — Validation

- [ ] Analytic two-attractor model basin with a known symmetry boundary: equal symmetric populations under symmetric integrand/quadrature.
- [ ] H2: symmetry-equivalent basins/populations within numerical tolerance.
- [ ] Homonuclear symmetric molecules (e.g. N2 if supported all-electron fixture available) to stress equal-basin convergence.
- [ ] Water/methane: molecular electron closure plus symmetry-equivalent H basin comparisons.
- [ ] Translation/rotation invariance of populations/charges/relative first moments.
- [ ] Quadrature-level convergence tests show tighter levels stabilize rather than simply checking one threshold.
- [ ] Compare selected basin populations/charges with an independent QTAIM program/reference when conventions and wavefunction are exactly matched. Store compact derived reference values/provenance.
- [ ] Keep Experimental unless the independent basin comparison is sufficiently broad and reproducible.

## Task 9 — Resource and regression gate

- [ ] Add ceilings for quadrature points per level, total attempted trajectories, steps per trajectory, cached states and serialized diagnostics.
- [ ] Tests prove oversized requests fail before quadrature allocation/trajectory execution.
- [ ] Run PR52/PR54 suites and existing Hirshfeld quadrature tests.
- [ ] Run full Tests & Quality and docs/registry checks.

**PR56 completion criterion:** openWFN produces basin populations/charges with explicit numerical convergence, closure and unresolved fractions, while accurately describing the numerical grid/trajectory approximation instead of claiming an exact analytic zero-flux surface.
