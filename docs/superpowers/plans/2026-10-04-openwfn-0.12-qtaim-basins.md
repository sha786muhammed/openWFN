# openWFN 0.12 QTAIM Basin Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add converged QTAIM basin assignment and integration for basin populations, charges, first moments, and closure diagnostics.

**Architecture:** Reuse QTAIM attractors and the shared analytic density-gradient engine. Basin assignment follows bounded steepest-ascent trajectories from deterministic multicenter quadrature points; integration owns convergence across quadrature levels, unresolved-weight accounting, trajectory caching checks, and zero-flux diagnostics.

**Tech Stack:** Python 3.10-3.13, NumPy, existing atom-centered quadrature, QTAIM topology engine, central resource budget, `ResultRecord`.

**Spec:** `docs/superpowers/specs/2026-10-04-openwfn-0.12-real-space-nto-qtaim-design.md`

## Global Constraints

- Basin identity is determined by the attractor reached by the density-gradient ascent trajectory.
- Unresolved trajectories remain unresolved; no nearest-nucleus fallback.
- Required properties: electron population, nuclear basin charge, first moments/dipoles, global/resolved closure.
- Atomic energies are out of scope for 0.12.
- Default absolute basin volume is not reported; any finite-domain volume is explicitly cutoff-defined.
- Convergence is checked across increasing quadrature levels.
- Resource ceilings apply to quadrature points, trajectory steps, refinement levels, and caches.
- Scientific status begins Experimental.

## Review Focus

- Diffuse/asymptotic quadrature points must not be silently assigned by geometric proximity.
- Non-nuclear attractors must receive their own basin rather than being folded into a nearby nucleus.
- Cache reuse must be guarded by geometric/gradient consistency, with a test that prevents cross-boundary leakage.
- A tiny unresolved point count can still carry non-negligible electron weight; convergence decisions must use unresolved electron contribution as well as count/weight.
- Charge/population closure must be reported raw; no renormalization of basin populations.
