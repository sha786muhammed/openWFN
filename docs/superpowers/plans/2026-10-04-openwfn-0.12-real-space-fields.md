# openWFN 0.12 ELF LOL NCI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ELF, LOL, and NCI analyses as thin, convention-explicit consumers of the shared real-space field engine.

**Architecture:** Put formula kernels in a focused `localization.py`/`nci.py` layer that consumes density, gradient, Hessian, and positive-definite kinetic-energy density from the core-fields PR. Field sampling and cube export reuse existing bounded grid/cube services; CLI/report/Workbench display precomputed registry results only.

**Tech Stack:** Python 3.10-3.13, NumPy, core real-space engine from PR 52, existing cube/export/report/Workbench stack.

**Spec:** `docs/superpowers/specs/2026-10-04-openwfn-0.12-real-space-nto-qtaim-design.md`

## Global Constraints

- ELF uses the explicit Becke-Edgecombe spin convention from the spec.
- `tau_PD` keeps the shared `1/2` convention; ELF explicitly uses `tau_B = 2*tau_PD`.
- Closed-shell default ELF is the common equal-spin value; unrestricted ELF requires explicit `alpha` or `beta`.
- LOL total and spin-channel forms remain separately labeled.
- NCI uses `s = |grad rho| / [2(3pi^2)^(1/3)rho^(4/3)]` and `sign(lambda2)*rho` with ordered Hessian eigenvalues.
- Density/KED floors and masks are explicit provenance, never hidden physical zeros.
- Scientific status begins Experimental.

## Review Focus

- Very low density must mask/flag ELF/LOL/NCI rather than create overflow/underflow artifacts.
- Restricted and unrestricted spin conventions must not be mixed under a single unlabeled result.
- Negative/near-zero Hessian eigenvalues in NCI must use deterministic ordering/tolerance.
- Display cutoffs must not mutate the underlying density-derived values.
- Cube/CSV exports must preserve masks, units, and analysis settings in provenance.
