## Shared field policy

- Inputs are PR52 density/gradient/Hessian/KED results only. Do not call `evaluate_ao_fields()` directly from every formula unless `realspace.py` exposes no suitable shared contraction.
- Every field carries density channel/spin, density floor, masks/cutoffs, units/convention and grid definition.
- Masked numerical points are represented as mask state/NaN in internal field arrays as appropriate; export/rendering decides presentation. Never turn “undefined below floor” into a physical zero silently.
- Grid requests use existing `molecular_grid_points`/chunking and `MAX_GRID_POINTS`.

## Task 1 — ELF spin formulation (TDD)

Use the approved convention:

- `tau_PD,sigma = 1/2 sum n_i,sigma |grad psi_i,sigma|^2`
- `tau_B,sigma = 2 tau_PD,sigma`
- `D_sigma = tau_B,sigma - (1/4) |grad rho_sigma|^2 / rho_sigma`
- `D0_sigma = (3/5) (6*pi^2)^(2/3) rho_sigma^(5/3)`
- `ELF_sigma = 1 / (1 + (D_sigma/D0_sigma)^2)`

- [ ] RED algebraic tests using manually supplied rho/grad/tau values with known ELF.
- [ ] RED limiting tests for homogeneous-electron-gas-style `D=D0 -> ELF=0.5`, and `D=0 -> ELF=1` when numerically defined.
- [ ] RED density-floor test proving points below floor are masked, not returned as zero.
- [ ] RED restricted closed-shell test proving alpha and beta are equal and default `elf` is explicitly labeled common spin-channel ELF.
- [ ] RED unrestricted test requiring `alpha` or `beta`; no default combined ELF.
- [ ] Implement pure function `elf_from_fields(...)` and calculation/grid wrapper.

## Task 2 — LOL convention (TDD)

Use total spinless convention:

- `tau_TF = (3/10) (3*pi^2)^(2/3) rho^(5/3)`
- `zeta = tau_TF / tau_PD`
- `LOL = zeta/(1+zeta)`

- [ ] RED exact algebra tests and monotonic behavior tests.
- [ ] RED density/KED floor tests; zero/near-zero denominator is masked according to explicit KED floor rather than divided blindly.
- [ ] RED total versus spin-channel labeling tests. Spin-channel Thomas-Fermi reference uses the corresponding spin-density convention and is never returned under unlabeled `lol` metadata.
- [ ] Implement pure `lol_from_fields(...)` plus calculation/grid wrapper.
- [ ] Ensure finite defined LOL lies in `[0,1]` within numerical tolerance; values outside due to invalid source fields produce diagnostics, not clipping that hides the issue.

## Task 3 — NCI/RDG (TDD)

Use:

`s = |grad rho| / [2 (3*pi^2)^(1/3) rho^(4/3)]`

and sorted density-Hessian eigenvalues `lambda1 <= lambda2 <= lambda3`, with signed-density descriptor `sign(lambda2)*rho`.

- [ ] RED exact algebra tests for known rho/gradient/Hessian tensors.
- [ ] RED eigenvalue-order tests including positive/negative/near-zero lambda2.
- [ ] Define `sign(0)` handling explicitly as zero descriptor within eigenvalue tolerance; record tolerance.
- [ ] RED low-density masking and optional high-RDG display/filter cutoff tests. Underlying raw rho/grad/Hessian remain unchanged.
- [ ] Implement `nci_from_fields(...)` returning rho, RDG, lambda2, signed density and masks.
- [ ] Produce bounded scatter rows `(signed_density, rdg, rho, mask/status)`; bound returned row count or deterministic downsampling if a full regular grid would exceed result-size policy.
