## Public/internal interfaces

Add to `analysis/basis.py` a single derivative-aware evaluator rather than a second basis implementation, for example:

```python
@dataclass(frozen=True, slots=True)
class AOFieldBatch:
    values: np.ndarray       # (n_points, n_ao)
    gradients: np.ndarray    # (n_points, n_ao, 3)
    hessians: np.ndarray     # (n_points, n_ao, 3, 3)


def evaluate_ao_fields(
    basis: BasisSet,
    molecule: Molecule,
    points_bohr: np.ndarray,
    *,
    derivatives: int = 2,
) -> AOFieldBatch:
    ...
```

`evaluate_ao()` remains public/backward compatible and delegates to/reuses the same shell machinery; do not duplicate normalization or pure transforms.

Create `analysis/realspace.py` with typed field records and functions conceptually equivalent to:

```python
evaluate_density_fields(data, points_bohr, *, kind="total")
evaluate_kinetic_energy_density(data, points_bohr, *, kind="total")
density_derivatives(data, *, points_bohr, kind="total") -> ResultRecord
kinetic_energy_density(data, *, points_bohr, kind="total") -> ResultRecord
```

Density-field payload must expose `rho`, gradient, symmetric Hessian and Laplacian. KED uses the density-matrix contraction of AO gradients with canonical `1/2` positive-definite convention and records the convention string.

## Task 2 — Density gradient/Hessian/Laplacian

For AO vector `chi`, AO gradient `g`, Hessian `H`, and density matrix `P`, implement the full product derivatives without assuming a shortcut that changes semantics:

- `rho = chi^T P chi`
- gradient from derivatives of both AO factors
- Hessian from AO Hessian/value terms plus both gradient-gradient cross terms
- Laplacian as Hessian trace

- [ ] Add RED tests on synthetic one-/two-AO density matrices where closed forms are available.
- [ ] Add a symmetry assertion/tolerance for returned density Hessians.
- [ ] Add restricted total/alpha/beta handling by reusing `density_matrix_for_kind()`.

## Task 3 — Positive-definite KED

`tau_PD = 1/2 * sum_mu,nu P_mu,nu grad(chi_mu) . grad(chi_nu)`.
