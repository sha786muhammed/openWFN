# Geometry tutorial

```bash
openwfn water.fchk summary
openwfn water.fchk geometry distance 1 2
openwfn water.fchk geometry angle 2 1 3
openwfn water.fchk bonds
openwfn water.fchk graph
```

Confirm atom numbering with the coordinate table before interpreting a measurement. Distances are in ångströms and angles in degrees.
