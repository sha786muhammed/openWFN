# openWFN 0.8.0a2 Trust Pass Implementation Plan

> **For implementation:** Execute this plan task-by-task using a test-first workflow. Keep the checkboxes current and commit after each independently verified task.

**Goal:** Ship a trustworthy 0.8.0a2 alpha whose installation guidance is unambiguous, whose first tutorial runs from the wheel, whose parallel batch path is bounded and tested, and whose ordinary CLI startup does not import Matplotlib.

**Architecture:** Keep the existing CLI and scientific model intact. Add a small resource-installation boundary for packaged examples, isolate plotting imports at the command that needs them, replace ordered process-pool mapping with a bounded completion-driven scheduler, and exercise the actual batch stack through a deterministic benchmark script. Release-facing metadata and documentation are updated only after these behaviors are passing.

**Tech Stack:** Python 3.10–3.13, `argparse`, `importlib.resources`, `concurrent.futures`, `pytest`, setuptools, GitHub Actions, MkDocs Material.

**Spec:** `docs/project/specifications/2026-09-25-0.8.0a2-trust-pass.md`

## Global Constraints

- Release version is exactly `0.8.0a2`.
- Python support remains exactly 3.10–3.13.
- Matplotlib remains a required dependency in this release but must be imported only by plotting execution.
- The packaged example must require no network access and must retain documented provenance and redistribution terms.
- Existing input-first CLI syntax and result schemas remain backward compatible.
- Multi-worker execution must bound submitted futures, persist completion-order records atomically, and emit the final manifest in input order.
- CI benchmark runs are correctness checks without wall-clock performance thresholds.
- REST services, MCP integration, and new scientific analyses are out of scope.
- Repository text must not contain assistant-product names or internal workflow/skill names.
- Do not tag, publish, merge, or push without separate explicit approval.

## Review Focus

- Existing destination containing one example file: extraction must fail before changing any packaged example; covered in Task 2.
- Worker future raising outside normal per-file error handling: batch execution must fail clearly and must not write a complete manifest; covered in Task 3.
- Faster later input completing before a slow first input: its per-input record must persist first while manifest order stays deterministic; covered in Task 3.
- Benchmark arguments with zero or negative counts/workers: the command must reject them without starting a batch; covered in Task 4.
- Clean installed wheel without repository examples: the example command and first analysis must still succeed; covered in Task 5.

```python
"""Install redistributable example inputs from the package."""

from importlib.resources import files
from pathlib import Path

EXAMPLE_FILENAMES = ("water.fchk",)


def install_examples(destination: Path, *, overwrite: bool = False) -> tuple[Path, ...]:
    destination = Path(destination)
    targets = tuple(destination / name for name in EXAMPLE_FILENAMES)
    conflicts = tuple(path for path in targets if path.exists())
    if conflicts and not overwrite:
        names = ", ".join(str(path) for path in conflicts)
        raise FileExistsError(f"example output exists: {names}; pass --overwrite to replace it")

    package = files("openwfn.example_data")
    destination.mkdir(parents=True, exist_ok=True)
    for name, target in zip(EXAMPLE_FILENAMES, targets):
        temporary = target.with_name(f"{target.name}.tmp")
        temporary.write_bytes(package.joinpath(name).read_bytes())
        temporary.replace(target)
    return targets
```

```python
import time
from concurrent.futures import Future, ThreadPoolExecutor
from pathlib import Path

import pytest

from openwfn.batch import BatchRecord, _run_parallel


def jobs(count: int):
    return [(index, (Path(f"input-{index}.xyz"), ("summary",))) for index in range(count)]


class ImmediateExecutor:
    last = None

    def __init__(self, max_workers: int):
        self.submitted = 0
        ImmediateExecutor.last = self

    def __enter__(self):
        return self

    def __exit__(self, *args):
        return False

    def submit(self, function, argument):
        self.submitted += 1
        future = Future()
        future.set_result(function(argument))
        return future


def record(argument):
    path, _ = argument
    return BatchRecord(str(path), "success")


def test_parallel_scheduler_bounds_initial_submission() -> None:
    completed = _run_parallel(
        jobs(20), 2, runner=record, executor_factory=ImmediateExecutor
    )
    next(completed)
    assert ImmediateExecutor.last.submitted == 4


def test_parallel_scheduler_yields_completion_order() -> None:
    def delayed(argument):
        path, _ = argument
        if path.name == "input-0.xyz":
            time.sleep(0.15)
        return BatchRecord(str(path), "success")

    completed = list(
        _run_parallel(jobs(3), 2, runner=delayed, executor_factory=ThreadPoolExecutor)
    )
    assert completed[0][0] != 0
    assert sorted(index for index, _, _ in completed) == [0, 1, 2]


def test_parallel_scheduler_propagates_worker_crash() -> None:
    def crash(_argument):
        raise RuntimeError("worker crashed")

    with pytest.raises(RuntimeError, match="worker crashed"):
        list(_run_parallel(jobs(2), 2, runner=crash, executor_factory=ThreadPoolExecutor))
```

- [ ] **Step 4: Implement the bounded scheduler**

Import `FIRST_COMPLETED`, `Executor`, `Future`, `wait`, and `Iterator`. Implement
an initial window of `workers * 2`, submit one replacement after each yielded
completion, and call `future.result()` before yielding:

```python
def _run_parallel(
    pending: list[tuple[int, tuple[Path, tuple[str, ...]]]],
    workers: int,
    *,
    runner: Callable[[tuple[Path, tuple[str, ...]]], BatchRecord] = _run_one,
    executor_factory: type[Executor] = ProcessPoolExecutor,
) -> Iterator[tuple[int, Path, BatchRecord]]:
    remaining = iter(pending)
    with executor_factory(max_workers=workers) as executor:
        futures: dict[Future[BatchRecord], tuple[int, tuple[Path, tuple[str, ...]]]] = {}

        def submit_next() -> bool:
            try:
                index, argument = next(remaining)
            except StopIteration:
                return False
            futures[executor.submit(runner, argument)] = (index, argument)
            return True

        for _ in range(min(len(pending), workers * 2)):
            submit_next()
        while futures:
            done, _ = wait(futures, return_when=FIRST_COMPLETED)
            for future in done:
                index, argument = futures.pop(future)
                yield index, argument[0], future.result()
                submit_next()
```

Use a callable protocol/type alias if needed to keep Python 3.10 typing and Ruff
clean. Do not catch `future.result()` exceptions in this helper.
