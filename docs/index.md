# openWFN

openWFN is a local, research-oriented toolkit for Gaussian wavefunction analysis. It provides one scientific engine through a direct command line, Python API, guided terminal workflow, reproducible reports, and a standalone 3D workbench.

## Start here

```bash
python -m pip install openwfn
openwfn water.fchk summary
openwfn water.fchk workbench water-workbench.html --open
```

Version 0.7 focuses on Gaussian FCHK calculations, geometry, topology, orbitals, density, population analysis, ESP, scientific export, and provenance. Molecular data stays on your computer.

Use [Quick start](quick-start.md) for a practical workflow or [Methods](methods.md) for equations and units.
