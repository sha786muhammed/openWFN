# Ammonia (NH₃) — openWFN example

This example demonstrates geometry analysis for a
trigonal pyramidal molecule.

## Files

- `ammonia.gjf` — Gaussian input file
- `ammonia.fchk` — formatted checkpoint
- `ammonia.xyz` — legacy project-generated geometry companion

The calculation and export versions were not recorded. See
[the corpus provenance record](../PROVENANCE.md#ammonia) before using these files
as evidence.

## Usage

From this directory:

```bash
openwfn ammonia.fchk
```
