## Responsibilities

The maintainer reviews changes, enforces project policy, manages releases, and
decides whether scientific claims have sufficient definitions, tests, evidence,
and limitations. Release authority remains with the current maintainer until this
file records another arrangement.

No person may approve a change where an unresolved conflict of interest prevents
independent judgment. The conflict must be disclosed in the pull request and an
independent qualified reviewer should be requested. If no suitable reviewer is
available, the change remains unmerged.

Maintainer status and paper authorship are separate decisions. Changes to this
policy require a reviewed pull request with a stated reason.
